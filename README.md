# Spotlight @crisxai5 — make.fun entry

This is the make.fun Spotlight entry for the "AI Agents / Crypto Insights / Web3" bounty brief. It packages the already-live X post (`POST.json`) so the poster rendering and publishing pipeline can be anchored and verified on-chain.

Files:
- `POST.json` — the live X post URL to reference.
- `main.ts` — Node 22 entrypoint that copies `POST.json` to `/output/POST.json`.
- `gen_poster.py` / `poster.png` — the generated 1080x1080 Spotlight poster.
- `CREATIVE.md` — the creative rationale.
- `title.txt` — the one-line title.
